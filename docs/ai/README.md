# AI & Document Intelligence Documentation (`docs/ai`)

---

## Overview

This directory documents the AI workspace architecture, feature specification templates, model evaluation metrics, and human-in-the-loop fallback strategies for the Sofzenix platform.

---

## Directory Contents
- `ai-architecture.md`: Python FastAPI microservice architecture, vector store indexing, LLM orchestration layers.
- `ai-feature-specification.md`: Standard specification template governing all AI features (Input, Output, Model, Prompt, Confidence, Human Review).
- `ai-evaluation.md`: Benchmark metrics (Precision, Recall, F1, Hallucination checks, Latency SLAs).
