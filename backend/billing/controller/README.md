# SaaS Billing Layers

- `controller/`: Subscription management & billing web controllers.
- `service/`: Subscription entitlement and usage metering services.
- `repository/`: Subscription & invoice persistence interfaces.
- `model/`: Billing entity domain boundaries.
- `dto/`: Checkout & subscription payload definitions.
- `config/`: Payment gateway client configuration.
- `exception/`: Entitlement & payment exceptions.
- `test/`: Entitlement test cases.
