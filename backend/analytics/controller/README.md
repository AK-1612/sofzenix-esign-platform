# Analytics & Audit Layers

- `controller/`: Analytics & Audit query REST endpoints.
- `service/`: Audit log aspect and metric aggregation services.
- `repository/`: Audit log persistence interfaces.
- `model/`: Audit entry domain boundaries.
- `dto/`: Analytics filter & report payload definitions.
- `config/`: AspectJ audit interceptor configuration.
- `exception/`: Export failed exceptions.
- `test/`: Audit log immutability test cases.
