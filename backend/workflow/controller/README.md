# Workflow Module Layers

- `controller/`: Workflow definition & execution REST endpoints.
- `service/`: Workflow state machine and SLA escalation services.
- `repository/`: Workflow instance persistence.
- `model/`: Workflow entity domain boundaries.
- `dto/`: Action request DTOs.
- `config/`: Workflow engine bean setup.
- `exception/`: State transition exceptions.
- `test/`: Workflow execution test cases.
