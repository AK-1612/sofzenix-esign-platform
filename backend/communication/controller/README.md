# Communication Hub Layers

- `controller/`: Communication log & retry controllers.
- `service/`: Email, WhatsApp, and SMS provider routing services.
- `repository/`: Communication log persistence interfaces.
- `model/`: Message entity domain boundaries.
- `dto/`: Send message request payload definitions.
- `config/`: Gateway credentials & template engine config.
- `exception/`: Notification delivery exceptions.
- `test/`: Mock gateway delivery test cases.
