# eSignature Module Layers

- `controller/`: Signature capture & verification controllers.
- `service/`: Signature orchestration and HSM PKI services.
- `repository/`: Signature request and certificate persistence.
- `model/`: Signature entity domain boundaries.
- `dto/`: Signature payload definitions.
- `config/`: Crypto provider configuration.
- `exception/`: Signature validation exceptions.
- `test/`: Signature test cases.
