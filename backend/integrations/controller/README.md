# Integrations & API Platform Layers

- `controller/`: Webhook management & public API controllers.
- `service/`: Webhook dispatcher and OAuth connector services.
- `repository/`: Webhook subscription persistence interfaces.
- `model/`: Webhook entity domain boundaries.
- `dto/`: Event payload definitions.
- `config/`: Connector OAuth2 configuration.
- `exception/`: Webhook delivery exceptions.
- `test/`: Webhook payload verification test cases.
