# Layouts Directory (`frontend/src/layouts`)

This directory will hold reusable structural layout wrappers:
- `DashboardLayout.tsx`: Sidebar navigation, header, notification center, breadcrumbs.
- `AuthLayout.tsx`: Clean layout for authentication, OTP verification, and password reset views.
- `SigningLayout.tsx`: Distraction-free full-screen view for eSignature recipients.
- `SettingsLayout.tsx`: Tabbed configuration layout for organization and billing settings.
