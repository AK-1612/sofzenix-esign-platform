# Hooks Directory (`frontend/src/hooks`)

This directory will hold custom React hooks:
- `useAuth.ts`: Access user identity, active tenant organization, and permissions.
- `useSignatureCanvas.ts`: Canvas signature drawing, undo, clear, and rasterization logic.
- `useDocumentViewer.ts`: Zoom, pan, page navigation, and field overlay state.
- `useWorkflowEngine.ts`: Drag-and-drop workflow node manipulation state.
