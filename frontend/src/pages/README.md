# Pages Directory (`frontend/src/pages`)

This directory will contain top-level page views and route components.

## Target Page Routes
- `/dashboard`: High-level overview of document activity and tasks.
- `/documents`: Document listing, filtering, upload, and status views.
- `/documents/[id]`: Interactive document preview, signing interface, and audit trail.
- `/templates`: Document generation template library and builder.
- `/workflows`: Visual workflow engine builder and execution tracking.
- `/ai-insights`: Contract analysis, risk summary, and semantic search interface.
- `/settings`: Organization, team, subscription, and API key management.
