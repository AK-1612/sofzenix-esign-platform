# Utils Directory (`frontend/src/utils`)

This directory will hold pure helper utility functions:
- `dateFormatter.ts`: Formatting timestamps, relative dates, and expiry counts.
- `fileHelpers.ts`: File size formatting, extension validation, MIME type checks.
- `validation.ts`: Form validators (email, phone, tax ID, password strength).
- `crypto.ts`: Client-side checksum calculations for document integrity verification.
