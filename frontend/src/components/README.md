# Components Directory (`frontend/src/components`)

This directory is designated for reusable, atomic UI components across the platform.

## Sub-directory Design Strategy
- `ui/`: Pure presentational components (Button, Input, Modal, Badge, Dropdown, Table).
- `document/`: Document-specific components (DocumentViewer, SignaturePad, PageThumbnail, FieldOverlay).
- `workflow/`: Workflow visualizer components (NodeCard, ApprovalTimeline, StepBadge).
- `analytics/`: Chart widgets and dashboard cards.

> Note: Implementation will happen in subsequent feature phases.
